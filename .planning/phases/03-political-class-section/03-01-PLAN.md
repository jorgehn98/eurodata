CREATE TABLE revolving_door_cases (

  source_url      TEXT        NOT NULL
);
```

`data/politics/president-salary.csv` — columns: `year,metric,value,unit,source,source_url`
- metric values: `president_salary_nominal` and `president_salary_real` — TWO rows per year (one nominal, one real)
- Cover 2010–2024; use NULL for years without BOE data
- Source: BOE Real Decreto retribuciones altos cargos (https://www.boe.es/buscar/act.php?id=BOE-A-2014-5441 and annual update decrees)
- Nominal values: gross annual salary as published in BOE
- Real values: nominal ÷ (INE IPC annual avg / 100) — base year 2015 = 100

`data/politics/minister-salary.csv` — same structure, metrics: `minister_salary_nominal`, `minister_salary_real`
- Minister (Ministro/a) base annual salary per BOE
- Cover 2010–2024

`data/politics/mp-salary.csv` — same structure, metrics: `mp_salary_nominal`, `mp_salary_real`
- MP (Diputado/a) annual salary per Congreso de los Diputados retribuciones page
- Source URL: https://www.congreso.es/web/guest/retribuciones

`data/politics/advisor-count.csv` — columns: `pm_name,term_label,year_start,year_end,count,source,source_url`
- One row per government term since 2004; count = total free-appointment positions (cargos de libre designación)

**Script structure:**

// scripts/seed-politics.ts
// Run: npx tsx scripts/seed-politics.ts
// Requires: NEXT_PUBLIC_SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY in .env.local

import { readFileSync } from 'fs';
import { resolve } from 'path';
import Papa from 'papaparse';
import { createClient } from '@supabase/supabase-js';
import * as dotenv from 'dotenv';

dotenv.config({ path: resolve(process.cwd(), '.env.local') });

const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!
);

const SPAIN_COUNTRY_ID = 26;

function parseValue(raw: string): number | null {
  if (raw === '' || raw === 'null' || raw === 'NULL') return null;
  const n = parseFloat(raw);
  return isNaN(n) ? null : n;
}
```

**Seeding functions:**

1. `seedPoliticalMetrics()` — reads `president-salary.csv`, `minister-salary.csv`, `mp-salary.csv` (each has `year,metric,value,unit,source,source_url` columns). Upserts to `political_data` table with `onConflict: 'country_id,metric,year'`. Sets `country_id = SPAIN_COUNTRY_ID`.

2. `seedAdvisorCount()` — reads `advisor-count.csv` (`pm_name,term_label,year_start,year_end,count,source,source_url`). Transforms to `political_data` rows: `metric = 'advisor_count'`, `year = year_start`, `value = count`, `unit = 'count'`. Upserts with `onConflict: 'country_id,metric,year'`. The `term_label` and `pm_name` should be stored in `source` field as JSON-like string or just `pm_name` — use `source` for the term label (e.g., "Zapatero 2004–08") and `source_url` for the provenance URL.

3. `seedPensions()` — reads `pensions.csv` (`name,role,pension_annual_eur,years_in_office,exit_year,source,source_url`). Upserts to `political_pensions`. Because political_pensions has no natural unique key, use `upsert` with `onConflict: 'name,exit_year'` — add a UNIQUE constraint in migration: `UNIQUE(name, exit_year)`.

4. `seedRevolvingDoor()` — reads `revolving-door.csv` (`person_name,political_role,entity_moved_to,year,source_url`). Upserts to `revolving_door_cases` with `onConflict: 'person_name,year,entity_moved_to'` — add UNIQUE constraint in migration.

5. `seedMedianSalaryNominal()` — reads `data/economy/median-salary-nominal.csv` (`year,value,source,source_url`). Upserts to `economic_indicators` with metric = `'median_salary_nominal'`, unit = `'EUR/year'`, `onConflict: 'country_id,metric,year'`.

**IMPORTANT:** Update the migration file to add UNIQUE constraints before running the seed:
